# Non Plus image gallery

A shared, downloadable collection of images for the Non Plus collective: radar screens, particle tracks, cells and embryos.

**Site:** https://jcoyle98.github.io/non-plus-image-gallery/

Every image has a **Download** button (saves the gallery copy, up to 1600 px) and, where there is one,
a **Full resolution** link to the original at its source. Each caption gives the image's author and licence.
If you use an image, credit it as the caption says.

## How it works

| What | Where |
|---|---|
| The images | `images/<section>/NNN-title.jpg` (JPEG, at most 1600 px on the long side) |
| Titles, authors, licences, sources, sections | `catalog.json` |
| The page | generated by `build.py` into `_site/` |
| Publishing | `.github/workflows/deploy.yml` rebuilds and deploys on every push to `main` |

Preview locally with `python3 build.py --serve`, then open http://localhost:8002.

## Adding images (instructions for Claude, and for anyone else)

When someone sends an image to add, follow these steps in order.

### 1. Check that we're allowed to share it

The site is public and invites people to download, so **only add an image if one of these is true**:

- It is **public domain** or **CC0**.
- It has a **Creative Commons** licence that allows sharing (**CC BY** or **CC BY-SA**, any version). Not NC/ND licences.
- The person who made it has **given permission** for it to be shared and downloaded here. Record that permission
  in `--contributor`, and use the licence text `Permission from <name>`.

If none of these is clear, **don't add it**. Ask the sender where the image comes from and who made it.
An image found on a website or social media is not automatically free to share.

### 2. Pick a section

Sections are listed at the top of `catalog.json`:

- `radar`: radar & scopes
- `tracks`: particle tracks
- `cells`: cells, micrographs & radiolaria
- `womb`: embryos & the womb

To create a new section, add it to `"sections"` in `catalog.json` first (key and display name).

### 3. Add it with the tool

Requires Python 3 and Pillow (`pip install pillow`).

**From Wikimedia Commons:** title, author, licence, source and full-resolution link are filled in automatically:

```
python3 tools/add_image.py --commons "File:Hurricane Gracie on radar scope in September 1959.jpg" --section radar
```

**From a file someone sent, or any URL:** supply the details yourself:

```
python3 tools/add_image.py ~/Downloads/photo.jpg --section cells \
  --title "Dividing cells" --artist "Jane Doe" \
  --licence "Permission from Jane Doe" \
  --contributor "Jane Doe, by email to John, 2026-10-20" \
  --source "https://janedoe.example/work"
```

The tool resizes the image, saves it as `images/<section>/NNN-title.jpg` with the next free number, and adds
its entry to `catalog.json`. It refuses images without a title, author, licence and contributor, and licences that
don't allow sharing.

### 4. Check, then publish

```
python3 build.py --serve          # look at http://localhost:8002 and find the new image
git add -A
git commit -m "Add image NNN: <title>"
git push
```

The site updates about a minute after the push. Image numbers never change once assigned,
so people can refer to "image 37" reliably. To remove an image, delete its file and its entry in `catalog.json`.
